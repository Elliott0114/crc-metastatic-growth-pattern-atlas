# Source Data

This directory contains the panel-level source data for the six main figures and
five supplementary figures in the associated manuscript.

- `figure_source_data/`: 30 main-panel files, 11 supplementary-panel files and
  supporting spatial/programme-length tables used by the displayed panels.
- `supplementary_tables/`: Supplementary Tables 1 and 2 in tab-delimited and
  Excel formats.
- `manifests/`: the final panel inventory.

The public raw data are not redistributed. Dataset accessions and source articles
are given in the manuscript and Supplementary Table 1.
