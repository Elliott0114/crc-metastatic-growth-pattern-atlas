# 使用说明

## 范围

唯一基准是 2026-09-21 Biology Direct 精修稿：5 张主图、6 张补图、
52 个图面、8 个工作簿和 127 个工作表。此目录是独立公开代码导出，
不包含稿件正文、投稿材料及未采用的探索分支，也不执行 FASTQ 流程。

注意：补表 4 的 `REC44_cross_context` 沿用了移除 KRT20 之前的空间定义。
公开代码单独复现这张历史表，主分析仍使用修正后的定义。此差异及其解释
记录在 [WORKFLOW.md](WORKFLOW.md) 和验证报告中，未擅自修改稿件基准。

## 本地运行

现有机器继续使用 `crc-metastatic-growth`，不要修改该受保护环境，
不要执行 `renv::restore()`。新机器按 `environment.yml` 单独创建环境。

```bash
conda run -n crc-metastatic-growth python reproduce.py check --mode quick
conda run -n crc-metastatic-growth python reproduce.py quick --output-dir /绝对路径/quick-run
conda run -n crc-metastatic-growth python reproduce.py verify --output-dir /绝对路径/quick-run
```

快速流程读取随仓库冻结的数值结果，不重新拟合模型。完整流程先按
[DATA.md](DATA.md) 准备矩阵及元数据，E-MTAB 配套包解压到同一输入根目录。
GSE294385 作者区域注释不随仓库或配套包发布；完整流程需从作者处获取，
再按 `DATA.md` 导出并核验。快速重绘不需要该文件。

```bash
conda run -n crc-metastatic-growth python reproduce.py check --mode full --data-dir /绝对路径/inputs
conda run -n crc-metastatic-growth python reproduce.py full --data-dir /绝对路径/inputs --output-dir /绝对路径/full-run
```

每次运行使用新的输出目录。输入缺失或校验失败时应停止；完整流程不会
回退到冻结结果。内部保留的日期目录用于保持原代码路径约定，不需要另行
复制历次稿件。模型重算的实际验证范围以 `reports/` 为准，不能将重绘成功
视为模型重算成功。
